# YourRole - версия ПР5

## Описание

В этой версии консольная предметная модель получила веб-интерфейс на Django. Проект и приложение связывают URL-маршруты с представлениями, которые загружают предметные данные через `JSONRepository`.

## Возможности

- Главная страница и разделы проектов, команд, участников и ролей.
- Страницы списков и подробного просмотра записей.
- Именованные маршруты с идентификаторами объектов.
- Ответ HTTP 404 для отсутствующей записи и обработка ошибок JSON-хранилища.

## Структура

- [`webproject/`](../../webproject/) - настройки Django и корневые маршруты.
- [`webapp/urls.py`](../../webapp/urls.py) - маршруты приложения.
- [`webapp/views.py`](../../webapp/views.py) - представления страниц.
- [`storage.py`](../../storage.py) и [`data/`](../../data/) - предметные данные.

## Запуск

```powershell
python manage.py check
python manage.py runserver
```

Основные страницы: `/`, `/projects/`, `/teams/`, `/participants/`, `/roles/`.

Эта папка содержит описание этапа; исходники находятся в корне репозитория.
