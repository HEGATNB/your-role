# YourRole - базовый этап перед ПР5

## Описание

Эта папка фиксирует подтверждённую основу проекта перед переходом к веб-части: предметные сущности Python и хранение данных в JSON. Отдельная методичка и отдельный снимок проекта для ПР4 в рабочей папке отсутствуют, поэтому README не приписывает этому этапу неподтверждённые функции.

## Подтверждённая основа

- Доменные классы `Project`, `Team`, `Participant` и `Role` находятся в [`models/`](../../models/).
- `storage.py` содержит `JSONRepository` для чтения и сохранения JSON-данных.
- Исходные данные находятся в [`data/`](../../data/).
- Вспомогательная логика подбора роли и статуса назначения находится в [`utils.py`](../../utils.py).

Это описание этапа, а не отдельная копия исходного кода. Текущие файлы проекта находятся в корне репозитория.
