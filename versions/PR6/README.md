# YourRole - версия ПР6

## Описание

В ПР6 веб-страницы YourRole оформлены системой шаблонов Django. Общая разметка вынесена в базовый шаблон, страницы разделов используют наследование, повторяющиеся карточки подключаются как компоненты.

## Возможности

- Наследование шаблонов через `extends` и переопределение блоков.
- Включаемые карточки проектов и ролей.
- Передача объектов и списков через контекст представлений.
- Условия и циклы для содержимого и пустых состояний.
- Именованные URL, фильтры и статические CSS, JavaScript и SVG.
- Страницы обзора, списков и деталей проекта, команды, участника и роли.

## Файлы

- [`webapp/templates/webapp/`](../../webapp/templates/webapp/) - HTML-шаблоны.
- [`webapp/static/webapp/`](../../webapp/static/webapp/) - стили, скрипты и изображения.
- [`webapp/urls.py`](../../webapp/urls.py) - именные маршруты.
- [`webapp/views.py`](../../webapp/views.py) - данные для шаблонов.

## Проверка и запуск

```powershell
python manage.py check
python manage.py runserver
```

Эта папка содержит описание этапа; исходники находятся в корне репозитория.
