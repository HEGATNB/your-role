# YourRole — распределение ролей в учебных командах

YourRole помогает организовать учебные проекты: хранит проекты, команды, участников и роли, сопоставляет требования роли с навыками участников и показывает состав групп в веб-интерфейсе.

## Что реализовано

- ПР1: начальный консольный сценарий проверки соответствия участника роли и вместимости команды (`main.py`).
- ПР2: модели предметной области, работа с коллекциями и JSON-хранилище (`models/`, `storage.py`, `data/`).
- ПР3: объектная модель `Project`, `Team`, `Participant`, `Role`, методы проверки соответствия навыков и управления составом, строковые представления объектов.
- ПР5: Django-проект с обзором и страницами проектов, команд, участников и ролей; детальные страницы используют идентификаторы и возвращают 404 для отсутствующих записей.
- ПР6: базовый и дочерние Django-шаблоны, включаемые карточки, контекст, условия, циклы, фильтры, именованные маршруты, собственные CSS/JavaScript, SVG-иконки и логотип YourRole.
- Автоматизированные проверки модели, JSON-данных и маршрутов.

Яндекс Практикум выполняется отдельно и в этот репозиторий не включён.

## Стек

Python 3.12+, Django 5.2, SQLite (конфигурация Django), JSON для предметных данных, pytest.

## Структура

```text
models/                 Объектная модель предметной области
data/                   Пример исходных данных в JSON
webproject/             Настройки и корневые маршруты Django
webapp/                 View-функции, маршруты, шаблоны и static-файлы
tests/                  Проверки моделей и JSON-хранилища
main.py                 Сценарий ПР1
storage.py              Чтение и обновление JSON-хранилища
utils.py                Подбор роли и статус назначения
manage.py               Управление Django-проектом
```

## Запуск

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Проверить консольный сценарий ПР1:

```powershell
python main.py
```

Проверить и запустить веб-приложение:

```powershell
python manage.py check
python manage.py runserver
```

Основные страницы: `/`, `/projects/`, `/teams/`, `/participants/`, `/roles/`. Для просмотра записи откройте страницу коллекции и выберите её карточку. Примеры идентификаторов из начальных данных — `1`.

## Проверки

```powershell
python -m pytest
python manage.py test
```

JSON-файлы находятся в `data/`. Репозиторий `JSONRepository` загружает записи в объекты Python и умеет сохранять изменения объектов обратно в соответствующий файл.
