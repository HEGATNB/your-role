# Team Roles Distributor

Сервис для распределения ролей между участниками учебных команд при работе над проектами.

## Назначение

Приложение предназначено для автоматизации процесса формирования учебных команд и распределения ролей внутри них. Сервис помогает преподавателям и студентам:

- создавать учебные команды под конкретные проекты;
- добавлять участников и управлять их составом;
- распределять роли с учётом навыков, предпочтений и требований проекта;
- отслеживать текущее состояние команды и её участников.

## Целевая аудитория

- **Преподаватели и кураторы** — формируют команды, контролируют распределение ролей, оценивают вклад участников.
- **Студенты** — указывают свои навыки и предпочтения, получают роль в команде, работают над проектом.
- **Учебные заведения** — используют сервис как инструмент организации командной работы в рамках образовательных программ.

## Описание предметной области

Предметная область — организация командной работы студентов над учебными проектами. Ключевая задача — оптимально распределить роли внутри команды так, чтобы каждый участник занимался подходящей ему деятельностью, а проект был реализован качественно и в срок.

Сервис учитывает:
- требования проекта к набору ролей;
- навыки и предпочтения участников;
- ограничения по количеству человек на роль;
- историю участия студентов в предыдущих проектах.

## Основные сущности

| Сущность    | Описание                                                                 |
|-------------|--------------------------------------------------------------------------|
| **Команда** | Группа участников, объединённая для работы над конкретным проектом.       |
| **Участник**| Студент, обладающий набором навыков и предпочтений по ролям.             |
| **Роль**    | Функциональная позиция в команде (например, тимлид, разработчик, тестировщик, аналитик). |
| **Проект**  | Учебная задача, для которой формируется команда и распределяются роли.   |

## Основные функции

- Регистрация и авторизация пользователей (участников и преподавателей).
- Создание и редактирование проектов.
- Формирование команд под проект.
- Добавление и удаление участников команды.
- Создание справочника ролей и их описаний.
- Распределение ролей между участниками (вручную и автоматически).
- Просмотр текущего состава команды и назначенных ролей.
- Хранение истории участия в проектах.

## План развития проекта

1. **ПР1** — создание репозитория, базовой структуры, README, начального сценария на Python.
2. **ПР2** — реализация моделей данных (команда, участник, роль, проект) и базовой логики.
3. **ПР3** — разработка веб-интерфейса на Django, подключение базы данных.
4. **ПР4** — реализация аутентификации и разграничения прав доступа.
5. **ПР5** — разработка REST API для интеграции с внешними системами.
6. **ПР6** — добавление алгоритма автоматического распределения ролей.
7. **ПР7** — тестирование, отладка, подготовка документации и защита проекта.
